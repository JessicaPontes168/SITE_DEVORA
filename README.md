# 🚀 DEVORA — Soluções Digitais

Site institucional desenvolvido para a Devora, empresa especializada na criação de sites profissionais, sistemas web personalizados e soluções digitais para empresas.

## 📌 Sobre o Projeto

O objetivo deste projeto é apresentar os serviços, portfólio e diferenciais da Devora por meio de uma interface moderna, responsiva e focada na experiência do usuário.

## ✨ Funcionalidades

* Apresentação institucional da empresa
* Seção de serviços oferecidos
* Portfólio de projetos realizados
* Processo de desenvolvimento
* Área de contato para orçamento
* Layout responsivo
* Animações e efeitos visuais modernos
* Navegação fluida entre seções

## 🛠 Tecnologias Utilizadas

### HTML5

* Estrutura semântica
* Organização de conteúdo
* Navegação entre seções

### CSS3

* Responsividade
* Flexbox e Grid
* Animações e transições
* Efeitos visuais modernos
* Identidade visual personalizada

### JavaScript

* Interatividade da interface
* Animações dinâmicas
* Melhor experiência de navegação

## 🎯 Objetivo

Criar uma presença digital moderna e profissional para apresentar os serviços da Devora e fortalecer sua marca no mercado de tecnologia.
